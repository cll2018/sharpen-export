# سياسة الخصوصية

_آخر تحديث: 3 أكتوبر 2026_

تلتزم Changsha Sharpen New Materials Co., Ltd. ("Sharpen"، "نحن") بحماية خصوصيتك. توضح هذه السياسة ما نجمعه من بيانات شخصية عبر www.sapu-cn.online ولماذا والخيارات المتاحة لك.

## 1. المعلومات التي نجمعها
- **بيانات الطلبات** — عند إرسال عرض سعر أو رسالة أو محادثة عبر نموذج التواصل أو مساعد الذكاء الاصطناعي أو واتساب، نجمع اسمك وبريدك الإلكتروني وشركتك وبلدك والمحتوى الذي تقدمه.
- **بيانات الاستخدام** — نستخدم تحليلات تحترم الخصوصية لفهم استخدام الموقع (الصفحات التي تمت مشاهدتها والمنطقة التقريبية ونوع الجهاز). لا نستخدم **أي** متتبعات إعلانية.
- **ملفات تعريف الارتباط** — تبقي ملفات تعريف الارتباط الضرورية الموقع يعمل؛ ويمكن تعطيل ملفات التحليل الاختيارية في المتصفح.

## 2. كيف نستخدم بياناتك
للرد على الطلبات وإعداد عروض الأسعار وتحسين منتجاتنا وموقعنا والوفاء بالالتزامات القانونية.

## 3. مشاركة البيانات
لا نبيع بياناتك الشخصية مطلقًا. نتشاركها فقط مع المعالجين الذين يشغّلون الموقع (إرسال البريد، استضافة Cloudflare) أو عندما يقتضي القانون ذلك.

## 4. الاحتفاظ
تُحفظ سجلات الطلبات فقط بالقدر اللازم لخدمتك وسجلات أعمالنا (عادةًا حتى 3 سنوات)، ثم تُحذف أو تُجهّل.

## 5. حقوقك
بموجب GDPR وCCPA وPIPL، يمكنك طلب الوصول إلى بياناتك أو تصحيحها أو تصديرها أو حذفها والاعتراض على معالجتها. راسلنا على {{ site.email }} لمارسة هذه الحقوق.
